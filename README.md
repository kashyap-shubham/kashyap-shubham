### How I Build

**Understand fundamentals deeply** — abstractions make more sense when internals are clear  

**Design for change** — software should evolve without major rewrites  

**Prefer clarity over cleverness** — readable systems scale better  

**Build end-to-end** — database → backend → frontend → real-time behavior  

**Iterate continuously** — small improvements compound over time
